アプリの追加方法

このアプリは無料のウェブアプリです（アプリストアからのダウンロードは不要です）。下のURL（QRコード）から開けば、iPhoneでもAndroidでもそのまま使えます。

アプリのアドレス
https://ats-business-hub.github.io/ats-app/

iPhone / iPad（Safari）

  1. Safariで上のアドレスを開きます（ChromeではなくSafariを使ってください）。
  2. 画面下（または上）の共有ボタンをタップします。
  3. 「ホーム画面に追加」を選び、追加します。

Android（Chrome）

  1. Chromeで上のアドレスを開きます。
  2. 「アプリをインストール」またはメニューの「ホーム画面に追加」を選びます。
  3. 出てこないときは、下の「追加する」ボタンを試してください。

パソコン

Chrome や Edge では、アドレスバー右端のインストールアイコンから追加できます。スマホで使うときは、QRコードを読み取ってください。

ホーム画面に追加すると、アプリのようにすぐ開けます（無料）。
